# Web 视觉样式

界面采用翡翠绿主色与中性背景，使用实体卡片和细边框表达层级。深色主题使用石墨绿背景，涨跌颜色沿用业务语义。共享样式位于 apps/dsa-web/src/index.css，应用框架位于 src/components/layout/Shell.tsx。

此次调整不改变路由、API 或报告字段；桌面端复用 Web 构建产物。支持系统减少动态效果偏好。英文文档未同步：本文为仓库内部中文视觉维护说明。

## 研究工作台布局

首页由页面标题、独立分析操作栏、左侧个股工作区与右侧报告区组成。导航按研究、投资管理和系统分组。没有选中报告时，展示研究起始页，提供选股、问股与持仓入口，不展示模拟行情。起始页提供中英文文案；窄屏改为单列，保留移动端抽屉导航。
